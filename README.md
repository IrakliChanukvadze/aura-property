# Aura Property workspace

Discovery workspace for a standalone residential-complex agency website and admin CRM.

Start with `AGENTS.md`, then `docs/product/business-rules.md`, `docs/product/decisions.md`, and `docs/product/open-questions.md`.

Status: business discovery. No application has been scaffolded, deployed, or connected to Pini. Decisions are recorded from the owner conversation as of 2026-10-06. Cloudflare is the requested deployment direction; topology remains undecided.

## Knowledge map
- `docs/product/business-rules.md`: agreed product behavior.

- `docs/design/references.md`: researched references, not approved designs.

Update these documents as discussion proceeds. Keep confirmed decisions distinct from proposals. Do not require the owner to repeat settled answers.
